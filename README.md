# Digital Clock

A modern animated digital clock built using HTML, CSS, and JavaScript.  
The clock displays the current time in **hours, minutes, and seconds** with smooth animated number transitions.

## Project Overview

This project demonstrates how JavaScript can be used to dynamically update webpage elements in real time. The digital clock reads the system time and updates the display every second. CSS animations are used to create a sliding effect for the numbers, giving the clock a modern and interactive look.

## Features

- Real-time digital clock
- Displays hours, minutes, and seconds
- Smooth sliding number animation
- Highlight effect for active digits
- Clean and modern UI design
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
digital-clock/
```

## Functionality

- JavaScript uses the **Date() object** to get the current time.
- The clock updates automatically every **1 second** using `setInterval()`.
- CSS transitions animate the numbers vertically to display updated digits.
- Active digits are highlighted to improve visual appearance.

## Output

The application displays a **live digital clock** showing:

```
HH : MM : SS
```

with animated sliding digits and highlight effects.
